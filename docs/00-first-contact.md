# Scroll World — первый контакт

Плагин делает **scroll-пролёт по мини-миру бренда** для сайта или лендинга: пока гость скроллит, камера летит сквозь сцены без склеек «из ниоткуда».

Как это устроено коротко:

1. Раскадровка: **M ∈ {3, 6, 9}** keyframe-панелей (M выбирается на Journey под проект) через Kie `gpt-image-2-text-to-image` — **каждая панель** в `media_aspect_ratio` из whitelist API; сшитый board только локально для просмотра
2. Видео-отрезки между кадрами через Kie `bytedance/seedance-2-mini` (Seedance 2 Mini, default **480p**, **4** с)
3. Русский текст поверх видео (можно править без новой генерации)

Команды: `/scroll-world-start`, `/scroll-world-run`.

Нужны: ключ `KIE_API_KEY` в `.env`, программа `ffmpeg`, Python + Pillow.

## Стартовые вопросы (только русский)

Director задаёт их **по-русски**, у вариантов — пояснение:

**О чём мир?** — открытый ответ своими словами.

**Бренд?**

- Взять с сайта — по URL
- Пришлю сам — цвета и имя
- Предложи сам — набросаем вместе

**Стиль?**

- Глиняная диорама (по умолчанию)
- Бумага / papercraft
- Игрушечный глянец
- Свой вариант

**Куда встроить?**

- В существующую страницу сайта
- Отдельная демо-страница

Дальше: journey → подтверждение бюджета → генерация. Все gates — тоже по-русски.
