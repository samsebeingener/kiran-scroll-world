# Scroll World — общение с пользователем (обязательно)

## Закон

**Весь диалог с пользователем — только на русском**, включая:

- приветствие и first contact
- вопросы intake / gates
- подписи к вариантам ответа (multiple choice)
- краткие пояснения «зачем этот вариант»
- статусы gates, ошибки, blockers, резюме шагов
- сообщения Fixic / QA для пользователя

**Английский разрешён только** в:

- промптах Kie gpt-image-2 / Seedance (модель)
- коде, путях файлов, JSON keys, CLI
- именах моделей и API slug

## Multiple choice — формат

Каждый вариант = **название на русском** + **1 короткая фраза «что это значит»**.

Плохо (запрещено):

```text
embed vs demo-page?
A) embed
B) demo-page
```

Хорошо:

```text
Как встроить результат на сайт?

A) Встроить в существующую страницу
   Блок вставится в ваш сайт (секция / компонент).

B) Отдельная демо-страница
   Сразу откроется готовый лендинг для просмотра и правок текста.
```

## First contact

Director / `/scroll-world-start` обязан начать по-русски: что делает плагин (1–2 предложения) → затем вопросы с пояснениями. Не сыпать английскими терминами без перевода.

## Gates

Формулировки STOP только по-русски. Технические счётчики (M, K, модели) — во внутренний `04-budget.md`, не в основной текст пользователю.

Пример после Journey (питч):

```text
Стоп. Вот замысел путешествия (как в 04-journey-pitch.md — показать текст как есть).

A) Утвердить
   Можно генерировать раскадровку.

B) Поправить
   Правите замысел → снова соберём journey и покажем питч.
```

Другие STOP (смягчённый жаргон):

- «Стоп. Раскадровка готова — ок / перегенерировать панели?»
- «Стоп. Первое видео — нравится / правки камеры или движения?»
